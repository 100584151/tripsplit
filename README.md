# TripSplit ✈️

**Set your budget. We plan the trip.**

🌍 **Live site:** https://100584151.github.io/tripsplit/

TripSplit is a budget-first travel planner (student project). Enter your budget, dates, group size and trip vibe, and TripSplit recommends complete trips you can actually afford.

## Features

- Budget search (€150 – €2,500) with dates, number of people (1–10) and trip vibes (Beach, City, Adventure, Food, Party)
- 14 destinations with a full cost breakdown: hotel, transport, activities and food
- Sorting (best match, cheapest, top rated) and favourites
- Day-by-day itinerary pop-up with partner booking links (Booking.com, GetYourGuide)
- "Split the Cost" calculator in every plan
- Free vs Premium (€4.99/month) plans
- Community trips you can copy into your search
- Fully responsive, no frameworks, no build step

## Run it

It's a single static file: open `index.html` in a browser, or publish it with GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root).
